# 🌈 Fundamento 3: Color e Iluminación (LED RGB)

En este módulo descubriremos el secreto de las pantallas: **La Síntesis Aditiva**.

Usaremos un **LED RGB**, que en realidad son 3 LEDs (Rojo, Verde, Azul) encapsulados en un solo cuerpo. Controlando la intensidad de cada uno, podemos crear más de 16 millones de colores.

> **💡 Concepto Clave:**
> * **Rojo + Verde =** Amarillo 🟡
> * **Rojo + Azul =** Magenta 🟣
> * **Verde + Azul =** Cyan 💧
> * **Rojo + Verde + Azul =** Blanco ⚪
