# ⚡ Fundamentos de Arduino y Electrónica (Insani Robotics)

Bienvenido al **Laboratorio de Conceptos** de Insani Robotics.

En esta sección no construimos robots completos; **construimos entendimiento**. Aquí encontrarás módulos independientes diseñados para dominar un componente electrónico o un concepto de programación a la vez.

> **👨‍🏫 Para el Docente:**
> Esta carpeta está diseñada bajo la filosofía de **"Aprendizaje Modular"**.
> Puedes usar estos módulos como lecciones individuales de 45 minutos antes de iniciar el armado de un kit complejo como Xplorer.

---

## 📚 Índice de Módulos

Cada módulo contiene: Diagrama de conexión, Código base (.ino) y Explicación teórica.

| Carpeta del Módulo | Temática | Componentes Clave | Dificultad |
| :--- | :--- | :--- | :---: |
| **[📂 F1: Sonido y Tonos](./F1_Sonido_Buzzer)** | Generación de frecuencias, notas musicales y alertas sonoras. | `Buzzer (Zumbador)` | ⭐ |
| **[📂 F2: Iluminación RGB](./F2_Iluminacion_RGB)** | Mezcla de colores, PWM (Pulse Width Modulation) y control digital. | `LED RGB` | ⭐⭐ |
| **[📂 F3: Sensores de Distancia](./F3_Sensores_Distancia)** | Principio de rebote de ondas, medición de tiempo y distancia (Ecolocalización). | `Sensor HC-SR04` | ⭐⭐ |
| **[📂 F4: Lógica de Motores (Puente H)](./F4_Control_Motores_L293D)** | Control de giro, tabla de verdad lógica y electrónica de potencia vs control. | `Driver L293D` | ⭐⭐⭐ |
| **[📂 F5: Comunicación Inalámbrica](./F5_Comunicacion_Bluetooth)** | Protocolos de comunicación Serial (UART), control remoto y App. | `Módulo HC-05/HC-06` | ⭐⭐⭐ |

## 🧠 Cómo usar este repositorio con tu Asistente de IA (Gemini)

Este repositorio está optimizado para trabajar con Inteligencia Artificial. Si eres docente, puedes pedirle a tu asistente que planifique tu clase basándose en estos módulos.

**Ejemplo de Prompt para copiar:**

> "Actúa como un experto en pedagogía STEAM. Analiza el contenido de la carpeta **[F3: Sensores de Distancia]**.
> 1. Explícame la analogía del 'eco' para niños de 10 años.
> 2. Crea 3 preguntas de opción múltiple para evaluar si entendieron cómo funciona el pin Trigger y el Echo.
> 3. Propón un reto rápido para modificar el código proporcionado."

---

## 🛠️ Requisitos Generales

Para realizar cualquiera de estas prácticas, necesitarás:

1.  **Placa de Desarrollo:** Arduino Nano (recomendado para Kit Xplorer) o Arduino Uno.
2.  **Software:** Arduino IDE instalado.
3.  **Conexiones:** Protoboard y cables Jumper (Macho-Macho / Macho-Hembra).
